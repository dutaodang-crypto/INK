# HisMS：组氨酸 / 碱金属 ESI 解卷积小程序

## 打开程序

在 Windows 上解压整个程序文件夹，双击 `start.bat`。浏览器会自动打开本地页面。关闭命令窗口即停止服务。

本机已验证可用。其他电脑需要 Python 3.10 或更高版本及 NumPy、SciPy；如果提示缺少依赖，在本文件夹运行：

```powershell
python -m pip install -r requirements.txt
python server.py
```

如果 8765 端口被占用，可用 `python server.py --port 8766`。仅监听本机回环地址，分析过程不访问外网。首次安装依赖需要联网。

## 页面操作

1. 从下拉框选择已附带的六份原始数据，或导入两列 TXT / CSV / TSV 轮廓谱。
2. 选择金属、最大电荷和峰高阈值；这些样品为氯化盐，保留“纳入含氯盐簇候选”。
3. 点击“分析并解卷积”。可输入 m/z 区间，或点击组分表的一行查看同位素包络。
4. 导出组分 CSV、完整 JSON 或谱图 SVG。JSON 包含设置、原始质量误差、残差、范围提示和疑似倍频关系。

输入要求：m/z 严格递增，无重复、NaN 或无穷值；至少 10 个点；支持一行文字表头。程序针对连续轮廓谱，不适合直接输入只有峰顶的质心峰表。图形只做保留极值的显示抽稀，计算使用全部原始点。

## 方法与数学含义

这是受化学组成约束的同位素包络解卷积，并非只把 m/z 乘以电荷，也不是通用 MaxEnt/UniDec 实现。

候选通式：`[nHis + kM + cCl + hH]^(z+)`，其中 `h = z - k + c`。

His 为中性 `C6H9N3O2`，精确质量 155.06947654 Da。程序使用原子质量并扣除电子质量，计算：

`m/z = (n*m(His) + k*m(M) + c*m(Cl) + h*m(H) - z*m(e)) / z`

默认候选限制：z = 1–2，n = 0–12，Cl = 0–6，金属数不超过 16；每个 His 最多失去一个质子，额外氢数不超过 z。n = 0 时只允许满足电荷平衡的纯盐簇。这是可修改的模型边界，范围之外的真实物种可能留在残差中。

处理顺序：

1. 301 点窗口的第 15 百分位数估算基线；负的校正强度截为零，不对原谱平滑。
2. 峰高和突出度至少为 `max(用户阈值×校正基峰, 5×稳健噪声估计)`。
3. 计算 C/H/N/O/Cl/金属的自然同位素分布。相同名义同位素阶数内按概率加权质量合并，属于包络近似，不解析超高分辨同位素精细结构。Li 使用优势同位素 7Li 参考质量，同时计算负侧 6Li；“reference_mz”并不总是最轻同位素峰或包络最高峰。
4. 以包络最强同位素定位候选。搜索窗口为 `max(0.015 Da, 指定 ppm)`；各候选局部对齐观测峰，同时保留对齐前的原始 ppm。默认 100 ppm 是为容纳这些数据的质量偏移，不能被当成高精度鉴定标准。
5. 至少匹配两条显著同位素线、可见概率质量不少于 75%，初筛余弦相似度至少 0.65。其他同位素的对齐窗口为 `min(0.05 Da, max(0.012 Da, 0.75×局部 FWHM))`。
6. 用非负最小二乘求 `min ||A*a - y||₂`，`a ≥ 0`。y 为检出的基线校正峰高，A 为候选包络；应当出现但没有检出的同位素线也作为零观测惩罚行。相同 m/z 的不同电荷候选靠包络间距与形状区分。
7. 表格报告占全部拟合系数之和至少 0.1% 的组分；拟合曲线与残差仍包含未报告的更小系数。拟合份额不等于离子流面积、浓度或摩尔分数。

“已匹配峰高比例”定义为 `sum(min(观测峰高, 拟合峰高))/sum(观测峰高)`，只针对已检出峰，不是总离子流解释率，不是鉴定置信度。“相对 L2 残差”包含应有而缺失的同位素惩罚。

“去金属 / 去电荷后的 His 聚集数”图把已报告组分按 n 汇总，质量为 `n×155.06947654`。n = 0 是纯盐组分。该图依赖组成模型，不是独立测得的中性物质浓度分布。

## 必须注意的数据问题

- 最终实验条件由用户确认：His 均为 5 mmol/L，金属浓度按文件名，全部为氯化盐，采集参数一致；与钠 PDF 内部 His-5mM 标记一致。NaCl/His 的配制摩尔比为 0.3:1 与 1:1，其他金属盐/His 为 1:1。
- `HisNa1.5mM-cluster-calibration-1.txt` 仅有 m/z 200.0001–262.5101。它不包含 PDF 中的高质量主峰；低浓度钠的全谱不能从该 TXT 恢复。程序会提示范围和低模型覆盖，不将该结果用于全谱比较。
- 两份钠 PDF 是已绘制的谱图。本次浓度比较使用 PDF 各自归一化峰高的近似读数，而非用不完整 TXT 与完整 TXT 做伪定量。
- 同一个 m/z 可能含多个组成。例如 `[3His+4Na-3H]+` 与 `[6His+8Na-6H]2+` 理论上完全重合；拟合拆分值依赖包络质量。
- 约为强峰 1/2 或 1/3 的低质量峰可能是 Fourier 质谱倍频伪峰，也可能有其他来源。程序只提示，不自动删除、不自动认作新化合物。
- 模型不包含其他阴离子、溶剂、碎片、杂质或多次侧链去质子化。较高拟合分数也不能确定配位位点、异构体或溶液结合常数。

## 命令行批量使用

```powershell
python deconvolution.py samples/HisNa5mM-cluster-calibration-1.txt --metal Na --output result_Na
python deconvolution.py samples/HisCs5mM-cluster-calibration-1.txt --metal Cs --output result_Cs
```

其他参数：`--no-chloride`、`--max-charge 3`、`--min-percent 1`、`--tolerance-ppm 80`、`--mass-offset-ppm -60`。最后一个参数仅在有独立校准依据时使用，报告默认没有修改原始质量轴。

## 验证情况

人工合成的完全同质荷比单电荷 / 双电荷重叠样品，输入包络系数 1000 与 650，恢复约 999.70 与 648.65。另验证了 Cs/Cl 在 -60 ppm 偏移时的识别、Li 的负质量侧同位素、Rb 的重同位素主峰及无效输入拒绝。六份实际样品均已运行；这不等于所有自动归属都已得到实验确证。

## 一键复核

```powershell
python verify.py
```

脚本用当前代码重跑六份附带样品，并与 `../analysis_data/summary.json` 对照基峰 m/z（±0.01 Th）、报告组分数和已匹配峰高比例（±0.002）。全部一致时退出码为 0。找不到参考文件时只打印本次结果、不做判定。
